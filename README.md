01 — About
I'm Abhirup Sahoo. I enjoy building web experiences that combine visual design, interaction, and useful functionality. My projects range from browser-based creative experiments to product-style interfaces.
- Interested in: interactive web, creative coding, browser-based computer vision, and modern UI.
- I care about: clear interfaces, thoughtful motion, and projects that people can actually try.
- Current approach: build a working version, test it, refine the details, then share what I learn.
